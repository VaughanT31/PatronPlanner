# Commands

*Every Patron Planner chat command.*

Patron Planner answers to `/patronplanner` and `/pp`. Push Planner also uses `/pp`, so if you have both, use `/patronplanner`.

| Command | What it does |
|---|---|
| `/patronplanner` | Help |
| `/patronplanner cards` | Use the card view |
| `/patronplanner classic` | Use Blizzard's list (or the button beside the order tabs) |
| `/patronplanner queue` | Show or hide the order queue |
| `/patronplanner shop` | The shopping list |
| `/patronplanner knowledge` | Knowledge still to earn (or middle-click the minimap button) |
| `/patronplanner options` | The options (also Esc > Options > AddOns, or left-click the minimap button) |
| `/patronplanner minimap` | Hide or show the minimap button |
| `/patronplanner debug` | Debug messages for bug reports |
